# 业务助手离线、排队或回答失败时，基金平台还能正常使用吗？

业务助手只提供平台说明与操作指导，不执行交易，也不是交易能否受理的前置条件。助手依赖问答服务和台式机上的本地模型节点；台式机关机、网络中断、节点离线、知识尚未就绪或请求较多时，可能显示暂不可用、等待或排队。

请根据助手页面状态稍后重试；已有问题应先查看当前结果，避免连续重复发送。业务助手不会因为排队而自动扣款，也不会替你提交申购、赎回或撤单。

可以返回“基金市场”“银行卡与资金”“交易记录”等页面正常进行已授权的模拟业务。若基金业务页面自身也报错，应按该页面的错误提示处理，不把所有故障都归因于模型。涉及具体产品、订单和资金的结论，以平台实际记录为准。
