# 业务助手

投资者和后台菜单中的“业务助手”提供平台操作、模拟交易规则和常见问题说明。沿用基金平台账号，无需注册问答平台账号。每个基金账号有独立会话；用户可以新建会话、查看历史、提问和取消等待中的回答。它不读取本人余额、银行卡或订单明细，不执行申购、赎回、转账、绑卡等业务操作。

## 如何使用

1. 登录基金平台，进入“业务助手”，检查连接状态。
2. 新建会话，输入问题，或选择快捷问题。例如“我的申购为什么还在等待确认？”、“两张模拟卡的余额能一起用吗？”、“修改默认卡后，赎回回款到哪张卡？”。每条问题最多2000字符。
3. 提交后可看到排队或生成状态，完成后查看回答及资料来源。不要因为仍在等待而连续重复提交；如果发送结果不确定，先刷新记录，相同问题的重试复用请求编号。
4. 节点离线、资料未就绪或服务繁忙时，根据页面提示稍后检查。可以继续使用基金市场、账户、交易记录和使用帮助，助手不是交易受理的前置条件。

资料只覆盖本项目模拟业务。15:00、T+1确认、T+3付款是默认或示例参数，以具体产品参数和订单实际状态为准；回答不能代替实际账户记录，也不提供真实投资建议。

## 服务和身份边界

浏览器仅调用基金同源`/api/assistant`。基金后端沿用登录、CSRF、停用账号及临时口令限制，每次从已认证账号派生用户标识；不接受浏览器指定用户、知识库或上游地址。向问答服务发送的只有用户输入的问题、请求标识和内部用户标识，不转发浏览器Cookie、基金登录口令或账户资产数据。

问答服务的固定`/internal/fund-assistant`接口使用独立服务密钥和专属私有知识库；外部身份映射为不可交互登录的技术身份，每次查询都校验所属用户和知识库。生成复用问答平台已有运行槽、计算队列及远程台式机模型，不在基金服务等待模型完成。消息提交快速返回202，页面只在待处理时轮询；处理期限、取消和队列容量由问答服务控制。

基金HTTP调用有1秒连接、3秒完整响应期限、2个并发名额及256KiB响应上限，禁止重定向和应用层自动重发。调用不占用数据库事务或清算执行线程；服务异常使用脱敏提示。历史由问答数据库保存，基金数据库没有本功能新增迁移。

## 配置和发布

本地默认关闭助手；菜单和使用帮助仍可访问，页面明确显示未启用。只在受控服务端设置以下变量：

| 变量 | 用途 |
| --- | --- |
| `FUND_ASSISTANT_ENABLED` | 基金侧开关，默认false |
| `FUND_ASSISTANT_BASE_URL` | 运维专用内部地址，浏览器不可设置 |
| `FUND_ASSISTANT_SERVICE_KEY` | 两服务共享的独立密钥，只保存在受保护服务端配置 |
| `FUND_ASSISTANT_KB_ID` | 问答服务固定的基金私有知识库ID |

线上通过`cdzdd/Ferrari_Server`统一发布。仅基金server和问答api连接专用内部网络，数据库、web和其他worker不加入；专用接口不经公网网关转发。沿用基金域名或IP入口及问答平台已有台式机认证，不新增域名或第二套大模型。运维先备份并升级问答、导入和索引知识，再发布基金，保留现有两项目数据。

知识维护及独立小包见[知识维护说明](assistant-knowledge.md)，接口、排队和隔离行为以实际测试及运维发布记录为准。未在远程台式机实际生成回答时，不把模拟节点测试或服务启动写成真实模型验收。
